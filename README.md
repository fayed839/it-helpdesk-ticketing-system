# IT Help Desk Ticketing & Service Request System

## Overview
An IT support portfolio project demonstrating how user incidents and service requests can be captured, prioritized, assigned, troubleshot, documented, resolved, and reported through a structured help-desk workflow.

This project connects my IT support background with the operational processes used by service desks and IT teams.

## Core Workflow
```text
User Request
    ↓
Ticket Creation
    ↓
Categorize + Prioritize
    ↓
Assign Technician
    ↓
Troubleshoot / Communicate
    ↓
Resolve
    ↓
User Confirmation / Closure
    ↓
Metrics + Knowledge Base
```
