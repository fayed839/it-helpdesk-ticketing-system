# Ticket Workflow and Sample Records

## Priority Model
| Priority | Example | Target Handling |
|---|---|---|
| P1 Critical | Major outage / severe business impact | Immediate escalation |
| P2 High | Important user/service significantly impacted | High priority |
| P3 Medium | Standard incident with workaround or limited impact | Normal queue |
| P4 Low | Minor issue / informational request | Planned handling |

Actual response targets should be defined by the organization rather than invented for this portfolio.
